# Changelog

## 1.0.0

First release.

- Frame timing: average and worst frame, slow frames, and how many of them had a GC.
- CPU on Linux: game thread, process, steal time and core clock.
- Garbage collections with pause times, allocations and the most allocated types.
- Console lines grouped by pattern.
- Log lines per plugin from the SwiftlyS2 log.
- Entity count and the most common entity classes.
- A summary in the log every minute, a CSV file, and `perflog` / `perflog report`.
